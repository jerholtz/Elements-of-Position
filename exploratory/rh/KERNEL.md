| File | What |
|---|---|
| `stations.csv` | n, own-origin n/2, inverse 1/n, prime flag |
| `weights.csv` | complementary pair at selected n and σ |
| `dual_real.csv` | sum of ends at t=0 |
| `dual_height.csv` | same sum with height t (sheet: log/cos) |
| `dated_product.csv` | finite Euler product through p ≤ p_cut |
| `one_centre.csv` | \|left/right\| = n^{1-2σ}; equals 1 only on σ=1/2 |
| `summary.csv` | counts and the two dual_real numbers |
