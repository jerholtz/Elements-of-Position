# Elements of Position

One figure. Two generators. Everything else reads.

Justin Erholtz. Record of 24 September 2026.

Where is 1? It is the lock: the place the pair meets itself.

## What this deposit is

A closed unit, and a cut that does not close. Two operators that never name an angle inside the step. An n-gon of diameter \(n\). Tables from one conversation-owned run. Five frozen parts. Drawings that read those tables.

It is not a new constant. It names a joint the constants already share.

1. *The Closed Unit* — the hold and the cut; the pair; the lock.

3. *Without a Landing* — the residual as an object.  
4. *Meetings* — marriage at five, two routes; docking \(1/(2\varphi^k)\).
